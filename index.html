你在一顆小行星上經營採礦站：先用手挖礦、裝船賺錢，手忙不過來時，就蓋機器、拉輸送帶，把那件事交給機器做。

Windows 電腦按這裡下載（約 80MB） Mac 電腦按這裡下載（約 130MB）

第一次打開（只要做一次）

這個試玩版是自己做的小遊戲，沒有跟 Apple／微軟付費認證，所以電腦第一次會擋一下。照下面做就好，很安全。

  1. 下載好之後，打開檔案總管 → 左邊的下載，找到「AsteroidWorks-Windows」壓縮檔。
  2. 在它上面按滑鼠右鍵 → 解壓縮全部… → 解壓縮。
    一定要先解壓縮！直接在壓縮檔裡面點兩下，遊戲會打不開。
  3. 打開解出來的「AsteroidWorks」資料夾，在有遊戲圖示的「AsteroidWorks」上點兩下。
  4. 如果跳出藍色視窗，先按其他資訊，再按仍要執行。
    Windows 已保護您的電腦
    Microsoft Defender SmartScreen 已防止某個無法辨識的應用程式啟動……
    其他資訊
    仍要執行不要執行

    按了「其他資訊」之後，下面才會出現「仍要執行」。

  1. 下載好之後，打開Finder → 左邊的下載項目。如果看到的是壓縮檔，先在它上面點兩下解開，會變成「礦星工坊」。
  2. 在「礦星工坊」上點兩下。會跳出這個視窗，按完成：
    未打開「礦星工坊」
    Apple 無法驗證「礦星工坊」是否包含惡意軟體……
    丟到垃圾桶完成
  3. 點螢幕左上角的蘋果 → 系統設定 → 左邊的隱私權與安全性 → 右邊一直往下捲到底。
  4. 會看到一行說「礦星工坊」已被阻擋，按它旁邊的仍要打開，然後輸入你的開機密碼。
    已阻擋「礦星工坊」以保護你的 Mac。仍要打開
  5. 再點兩下「礦星工坊」，跳出的視窗按仍要打開。之後就能直接打開了。
Mac 用 Safari 下載會自動解開；用 Chrome 下載的話要自己點兩下壓縮檔。

怎麼玩

  • 主選單按「開始遊戲」。遊戲會自動存檔，關掉再開會接著玩。
  • 滑鼠左鍵：點東西、放機器、拖曳拉輸送帶。滑鼠右鍵：看那個東西是什麼。
  • 不知道怎麼辦也沒關係，隨便試試看——你卡住的地方，就是我最想知道的地方。

玩的時候，想到什麼就說

遊戲畫面右上角一直有一個 寫下想法 按鈕。

看不懂、卡住、覺得好玩、覺得無聊、畫面太亂——想到就按，打一句話，按「送出」，就會直接傳給我，不用另外截圖或傳檔案。

遊戲也會記下你玩到哪一關、玩了多久，跟你的想法一起送來，讓我知道是在哪裡發生的。不會收集其他資料。
